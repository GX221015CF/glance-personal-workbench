# 来源与收录范围

整理日期为 2026 年 11 月 15 日，展示版本为 v0.1.0。项目作者已审阅通过代码、文档与媒体，并授权以公开 GitHub 仓库展示。

## 源码依据

主要输入为工作区内维护目录 `../glance`。来源清单逐项记录原文件的相对位置、原始 SHA-256 和适配类型。该源目录在整理时尚无 Git HEAD，因此版本定位采用文件指纹。

收录范围包括 Python 业务模块、六页前端资源、必要配置及五个 include 组件、学校连接器源码、选定离线回归与公开 OpenAPI 定义。新增入口为 `run.py`、`app/workbench_config.py`、安装及验证工具。

主要适配如下。

- 默认页面与桥接端口改为 8180／8182，Google 回调、前端、扩展匹配和测试一并更新。
- 数据根改为仓库内 `.local` 或显式指定目录，Google、学校、ima、日历、缓存、任务和审计都在该范围保存。
- 旧版迁移回退路径限定在独立数据根，WorkBuddy 偏好读取也使用独立位置。
- 固定个人脚本路径改为独立数据目录中的可选脚本目录。
- WorkBuddy 以空路径示例开始，网络配置保留空应用代理，Google API 控制台链接采用通用入口。
- JSDOM 测试依赖改为仓库自己的 npm 依赖。

Electron 桌面构建、完整组件试验场、个人数据库、运行日志、账号会话、密钥、历史调试截图和构建输出留在维护工作区。所需 Glance 官方可执行文件通过校验安装，`bin` 属于 Git 忽略项。

`docs/public-files.json` 是展示版本的明确公开清单，记录文件大小和 SHA-256。清单自身仅列路径，提交审查再通过 Git 回读核验。本地初稿提交为 `830230e`，发布所需文档修订在后续提交中保留。

## 后续更新方式

维护版本继续在原工作台迭代。更新展示副本时先比较来源清单，再移入所需修改、复核隐私和依赖，重新执行验证并保存本地版本。相应业务数据由每个实例独立管理。
